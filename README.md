# dropnook's Community Applications repository

Templates for Unraid's Community Applications (CA) — the apps and plugins dropnook maintains.

- `ca_profile.xml` — who we are, where support happens
- `plugins/unraid-secretary-office.xml` — [Unraid Secretary Office](https://github.com/dropnook/UnraidSecretaryOffice), a small office for your Unraid server (backups, restores and a restore drill, snapshots, logs, a night watchman who also reads a UniFi router's log, partner offices, housekeeping, EmbyCache)
- `templates/dropnook.xml` — [Dropnook](https://github.com/dropnook/dropnook.app), instant sharing for your home network, like AirDrop for every device. A single container for your network only (`SHARING=off`); sharing single files or texts to the internet needs the second container of the [Compose stack](https://github.com/dropnook/dropnook.app#installation)
