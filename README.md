# dropnook's Community Applications repository

Templates for Unraid's Community Applications (CA) — the apps and plugins dropnook maintains.

- `ca_profile.xml` — who we are, where support happens
- `plugins/unraid-secretary-office.xml` — [Unraid Secretary Office](https://github.com/dropnook/UnraidSecretaryOffice), a small office for your Unraid server (backups, restores, snapshots, logs, a night watchman, housekeeping, EmbyCache)

Support and issues: https://github.com/dropnook/UnraidSecretaryOffice/issues
