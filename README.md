# dropnook's Community Applications repository

Templates for Unraid's Community Applications (CA) — the apps and plugins dropnook maintains.

- `ca_profile.xml` — who we are, where support happens
- `plugins/unraid-secretary-office.xml` — [Unraid Secretary Office](https://uso.dropnook.app): a whole team supports you in running your Unraid server, right in Unraid's web UI — backup and restore from every place with a restore drill, snapshots, partner servers over their own Tailscale network, a media cache for Emby, Jellyfin and Plex, the mover, a night watchman and every log in one place.
- `templates/dropnook.xml` — [Drop](https://github.com/dropnook/dropnook.app): instant sharing for your home network, like AirDrop for every device. A single container for your network only (`SHARING=off`); sharing single files or texts to the internet needs the second container of the [Compose stack](https://github.com/dropnook/dropnook.app#installation)
